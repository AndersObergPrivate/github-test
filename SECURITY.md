# Security Policy

## Supported Versions

We take security seriously and strive to address security issues promptly.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue
2. Send a detailed report to the repository maintainers
3. Include the following information:
   * Description of the vulnerability
   * Steps to reproduce the issue
   * Potential impact
   * Suggested fix (if available)

### What to Expect

* You will receive an acknowledgment within 48 hours
* We will investigate and provide updates on the status
* Once the vulnerability is confirmed, we will work on a fix
* We will notify you when the fix is released
* Credit will be given to the reporter (unless anonymity is preferred)

## Security Best Practices

When contributing to this project:

* Never commit sensitive information (passwords, API keys, tokens)
* Use environment variables for configuration
* Keep dependencies up to date
* Follow secure coding practices
* Report any security concerns you discover

Thank you for helping keep this project secure!

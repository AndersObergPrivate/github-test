# Roadmap Directory

This directory contains all roadmap planning documents for the Developer Relations team.

## 📁 Directory Structure

### `/quarters/`
Contains quarterly roadmap documents that provide a high-level overview of initiatives planned for each quarter.

**Naming Convention**: `YYYY-QX.md` (e.g., `2024-Q1.md`, `2024-Q2.md`)

### `/initiatives/`
Individual initiative documents with detailed plans, timelines, and tracking information.

**Naming Convention**: `[initiative-name].md` (use lowercase and hyphens)

Examples:
- `developer-documentation-refresh.md`
- `community-champions-program.md`
- `sdk-modernization.md`

### `/templates/`
Template files to use when creating new roadmap documents.

Available templates:
- `initiative-template.md` - Template for individual initiatives
- `quarterly-template.md` - Template for quarterly roadmaps

## 🚀 Getting Started

### Creating a New Initiative

1. Copy the initiative template:
   ```bash
   cp templates/initiative-template.md initiatives/your-initiative-name.md
   ```

2. Fill in all sections with relevant information

3. Create a GitHub issue and link it to the initiative

4. Submit a PR for review

### Creating a Quarterly Roadmap

1. Copy the quarterly template:
   ```bash
   cp templates/quarterly-template.md quarters/YYYY-QX.md
   ```

2. Fill in all planned initiatives for the quarter

3. Review with the team and stakeholders

4. Submit a PR for approval

## 📊 Viewing the Roadmap

- Browse quarterly roadmaps in `/quarters/` for a high-level overview
- Check individual initiatives in `/initiatives/` for detailed information
- Use GitHub Issues and Projects for real-time status tracking
